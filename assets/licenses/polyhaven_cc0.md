# Poly Haven CC0 environment sources

The environment sprites under `res://assets/2d/environment/polyhaven/` are
original Bespren renders derived from Poly Haven 1k GLTF source models.

- License: CC0 1.0 Universal
- License page: https://polyhaven.com/license
- Asset pages: https://polyhaven.com/a/<asset_id>
- Offline source workshop: `res://tools/art/blender/bespren_map_asset_workshop.blend`
- Reproducible renderer: `res://tools/art/render_polyhaven_environment_sprites.py`

Used asset IDs are recorded with output hashes and atlas regions in
`res://assets/2d/environment/polyhaven/polyhaven_asset_manifest.json`.
