# KayKit Dungeon Remastered CC0 source models

Structure, salvage, camp-furniture, and ruin sprites derived from the
KayKit : Dungeon Remastered Pack (1.1) are original Bespren renders. The
source models are reskinned to `BESPREN_PALETTE` before baking, so no KayKit
texture or material ships; only the geometry informs the silhouette.
